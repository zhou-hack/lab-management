# 固定设备管理 · 架构与清单

> 产品定稿 2026-10-14：**纯管理员设备管理**——系统仅 ADMIN 角色可用，无教师、无学生、无设备借用申请。
> 管理员能力：空间维护、设备分类/型号/台账管理、设备迁移登记、保管人指派。
> 本文档描述当前实施状态；PRD 完整规划（借用审批、多角色等）见 [权限清单](权限清单.md) 与 [流程清单](流程清单.md) 顶部注记。

### 1.2 分层与请求链路

```
浏览器（Vue SPA, 5173）
  │  Axios：Authorization: Bearer <token>，统一 Result{code,msg,data}
  ▼
Vite 代理 → Spring Boot 8080（JVM 时区 UTC）
  │  SaInterceptor（/**）：登录校验 + @SaCheckPermission 权限码校验
  ▼
Controller（@RestController，参数校验/编排，返回 Result/PageResult）
  ▼
Service 接口 + Impl（业务规则，事务边界，Instant UTC 审计）
  ▼
Mapper（MyBatis-Plus BaseMapper + @Select，LambdaQueryWrapper）
  ▼
MySQL（DATETIME(3) 存 UTC；id 雪花 BIGINT 序列化为字符串）
```

- 权限数据源：`StpInterfaceImpl` 实时查 `selectRoleCodes`/`selectPermissionCodes`（sys_user → sys_user_role → sys_role → sys_role_permission）
- 时间契约：入参 ISO 8601 带偏移量（`OffsetDateTime`→`Instant`），出参公共序列化器输出 `2026-10-14T01:00:00.000Z`
- 菜单契约：DB `menu_type`（DIRECTORY/PAGE/ACTION）→ 前端 M/C/F；`route_path` 与前端组件白名单 `viewModules` key 一致

### equipment 模块表结构（④ 建表）

| 表 | 说明 |
|---|---|
| equipment_category | 多级分类树（parent_id 自关联，最多二级：根分类+子分类） |
| equipment_model | 型号（挂分类，品牌/规格/含存储介质标记） |
| equipment_asset | 台账（每台一行：资产编号唯一、序列号、实验室、部门、存放位置、保管人、购置信息、价值分级、状态） |
| equipment_location_history | 位置变迁历史（追加型，deleted 恒 0） |
| equipment_booking / equipment_usage | 借用链表（结构保留、功能已移除） |

### 关键列约定

- 主键：雪花 BIGINT（`ASSIGN_ID`），接口序列化为字符串；种子用固定小 ID（分类 101-146、型号 201-246、台账 30001-30399、菜单 161-172）
- `equipment_asset.status`：`IDLE`（空闲）/ `MAINTAINING`（维护中）/ `SCRAPPED`（已报废，最终态）；RESERVED/IN_USE 随借用功能移除（列 CHECK 定义保留兼容）
- `value_level`：`NORMAL` / `VALUABLE`，NULL=待分类
- 公共字段：id/create_time/update_time/deleted（BaseEntity 覆盖）

## 7. 关键业务规则

1. **登录锁定**：密码连续失败 5 次锁定 30 分钟（failed_login_count/locked_until）
2. **台账删除/迁移**：迁移仅允许空闲（IDLE）设备；删除为逻辑删除
3. **位置历史**：迁移在事务内同时更新台账当前位置并追加 equipment_location_history
4. **价值分级**：已移除（2026-10-22），台账不再登记/展示价值分级；`value_level` 列零改表保留未使用
5. **目录视图收敛**：无 `equipment:asset:update` 权限的查询自动收敛为"在架且启用"（服务端强制，当前仅 ADMIN 有全量视图）
6. **审计填充**：MyMetaObjectHandler 填 create_time/update_time（UTC）；create_user_id/update_user_id 由服务层按登录人写入
