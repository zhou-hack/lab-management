## 三、优化点清单（本次落地）

### 3.1 矩阵重构（PeriodMatrixDay.vue 重写）

1. **行列转置**：行=场地（按区域分组：实训楼/教学楼/X楼/其他区域，与总览同口径），列=第 1-12 节（一屏放下，零横向滚动）；节次列表头 sticky 置顶（节次名+时刻）
2. **行头信息层级**：场地名 + 当前状态徽章（空闲/占用中/预留/已释放/不可用，pill 胶囊，口径即原总览 labState 四态，提取为 `booking.constants.labStateOf` 共享）+ 类型·容量·位置
3. **工具条**：场地名/位置关键词检索、类型筛选（教室/实训室）、"仅看当前可约"开关（隐藏无可约节次行）、折叠全部/展开全部、匹配计数（X/57 场地）
4. **分组折叠**：组头显示"区域名 + 空闲 X/Y + 占用中 N"；折叠后变聚合行——各节次该组"空闲数/总数"（如 4/6），零空闲橙色警示
5. **节次筛选联动**：筛选条选节次 → 矩阵对应列表头蓝色高亮
6. **点选交互**：点空格带入场地+起始节次，同行再点完成区间（区间内全空闲才成段，口径与渲染同源 `buildPeriodCellMap`）；选中格蓝色描边
7. **响应式**：≤900px 窄屏行头收窄、隐藏容量元信息与列头时刻，保证 12 节次完整可见
8. **状态自动流转**：nowTick 分钟级驱动，已过去/即将占用/徽章随当前时刻自动重算

### 3.2 总览板块评估与合并结论

- **重合度**：总览卡片与矩阵同源同数据（occupancy 接口），功能 90% 重叠（状态展示、点选场地、板块分组）
- **互补性**：总览独有的"当前四态徽章 + 老师信息"已迁移至矩阵行头徽章与占用格文本
- **结论：合并可行，已删除独立总览板块**——BookingList.vue 由 1600+ 行瘦身至约 880 行，删除模板 122 行、逻辑 260+ 行、死样式 170 行；双份 occupancy 请求降为单份（矩阵全天窗口）
- 近期预约（24h）、预约记录列表不受影响，保持不变

## 四、新增功能使用说明

| 功能 | 操作 |
| --- | --- |
| 定位场地 | 工具条输入名称/位置关键词，或按类型筛选 |
| 快速看空闲 | 勾选"仅看当前可约"；或折叠全部后看各组聚合行的节次空闲数 |
| 查单场地一周 | 选定场地后切"周日历"（教师端；点日期头跳回当日矩阵） |
| 发起预约 | 矩阵中点目标场地行的空闲格 → 再点结束节次格 → 右上"发起预约" |
| 场地当前状态 | 行头徽章（仅当天有占用中/预留/已释放细分；非当天显示空闲/已占用） |
