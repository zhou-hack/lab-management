## 五、当前守护架构（重启后自恢复）

```text
登录 Windows
  └─ HKCU Run 键（2 项）
      ├─ LabBackend8081 → wscript(隐藏) → start_lab_backend.ps1 → java -jar（8081，UTC）
      └─ LabFrontend5173 → wscript(隐藏) → start_lab_frontend.ps1 → node vite（5173）
日志：C:\Users\wyq\lab_backend_daemon\lab-backend.log / lab-frontend.log
```

- 进程由 WMI/系统托管：无控制台窗口、不随终端关闭、不受开发会话回收影响。
- 手动拉起（如进程被杀）：双击对应 `.vbs`，或执行 `reg` 键中的命令。
- 注意事项：① 后端更新代码后需重新 `mvnw package` 并重启 java 进程才生效；② `lab_backend_daemon` 目录不要删除；③ 本机 8080 仍可能被其他项目（cmzs-backend）占用，与本系统 8081 互不干扰，请勿改动本系统端口。
