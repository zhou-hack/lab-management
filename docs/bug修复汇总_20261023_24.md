# Bug 修复汇总(2026-10-23 18:00 ~ 2026-10-24)

时间范围:2026-10-23 晚 18:00 至 2026-10-24 下午,按模块分组,共 23 项。

## 一、登录与通用

### 1. 老师账号无法登录
- 现象:使用前端快捷登录按钮登录老师账号失败。
- 根因:[LoginView.vue](file:///d:/实验室管理/try/lab_management/frontend/src/views/LoginView.vue) 快捷登录写死的演示账号与 `dev_mock_data.sql` 种子账号不一致。
- 修复:快捷登录账号改为种子中真实的学工号账号。

### 2. 其他 IP 客户端无法访问(CORS 跨域)
- 现象:局域网其他设备访问系统,跨域预检失败无法进入。
- 根因(双因):[CorsConfig.java](file:///d:/实验室管理/try/lab_management/src/main/java/com/labmanage/config/CorsConfig.java) 白名单写死两个历史 IP;[JwtAuthFilter.java](file:///d:/实验室管理/try/lab_management/src/main/java/com/labmanage/common/security/JwtAuthFilter.java) 对无凭证头的 OPTIONS 预检一律回 401,请求到不了 Spring CORS 处理器。
- 修复:CorsConfig 改用 `allowedOriginPatterns` 支持网段通配(localhost + 私网网段任意端口,生产用环境变量收敛);JwtAuthFilter 放行 OPTIONS 预检;dev/test yml 同步更新。
- 验证:局域网 Origin 预检 200 且 ACAO 正确回显;白名单外 Origin 预检 403。

### 3. 设备申请与导入导出接口 403
- 现象:拉取最新代码后设备相关接口全部 403。
- 根因:设备申请、设备导入导出相关权限的种子脚本未执行插入。
- 修复:补执行权限种子脚本。

### 4. 部门下拉选项接口 403
- 现象:admin 等业务角色打开设备管理页面,部门下拉加载 403。
- 根因:该基础数据选项接口绑定了仅 OPS_ADMIN 持有的 system 级权限。
- 修复:非敏感基础选项接口移除业务权限校验,登录即可用。

## 二、场地预约

### 5. 场地详情「近期排课与占用」误报场地可用
- 现象:场地已有未来维修记录,详情弹窗却显示「未来 7 天暂无预约,场地各时段可用」。
- 根因:该模块只查场地预约数据,未加载维修时段。
- 修复:并行拉取生效中的维修窗口,与预约条目混合后按日期分组、按时段排序展示。

### 6. 老师预约页维修时段可点选造成体验断档
- 现象:维修覆盖的节次仅在后端提交层拦截,前端格子仍可点选,提交才被拒。
- 修复:单场地可用时段接口返回维修段数据,前端将维修覆盖节次直接置灰禁用不可选;后端在预约提交、管理员批准、周期预约提交/批准四个入口统一校验重叠,形成闭环。

### 7. 场地节次只能连续选择
- 现象:老师预约时节次只能连续选,无法跳选。
- 修复:改为点按 toggle 多选模式,支持跳选非连续节次,提交时自动拆分为多个预约单。

## 三、设备模块

### 8. 设备型号管理搜索索引不准确
- 现象:型号管理页单一 keyword 混合搜索,匹配结果不符合预期。
- 修复:拆分为型号码、设备名称两个独立搜索项,各自 like 匹配 AND 组合,品牌不再参与;前端两个 el-autocomplete 均带 typeahead 联想(输入片段查询前 10 条去重)。

### 9. 新增设备台账接口 500
- 现象:新增设备台账直接 500。
- 根因:设备台账表实体漏写已存在的 NOT NULL 列 `labId`。
- 修复:实体字段与表结构对齐,同步补齐 DTO、VO、列表展示及 Excel 导入导出的实验室 ID 字段。

### 10. 设备目录查询功能完全失效
- 现象:老师/学生端设备目录无论输入什么都过滤不出目标数据。
- 根因:前端 EquipmentDirectory.vue 仍传旧的 `keyword` 参数,后端已拆分为 `assetCode`/`equipmentName`,查询条件被完全忽略。
- 修复:前端拆为资产编号、设备名称两个带联想的独立输入框,AND 组合,参数命名与后端对齐。

### 11. 教师设备借用申请被自动批准
- 现象:教师提交的设备申请刚发出就显示已批准,管理员看不到待审批单据,审批流程失效。
- 根因:EquipmentBookingServiceImpl 中教师申请与学生代理申请走了直通逻辑,直接置已批准。
- 修复:所有教师申请统一进入 PENDING_ADMIN 待管理员终审;学生非代理申请保留教师初审环节。

### 12. 学生设备申请绕过教师初审
- 现象:学生(含持有助理授权的学生)提交申请直接到管理员终审,且申请表单没有审批教师选择入口。
- 修复:所有学生申请强制必选审批教师,初始状态落 DRAFT 待教师初审,初审通过后才流转管理员终审;前端 BookingApplyDialog 对所有学生显示审批教师必选下拉;同步修复该组件设备远程搜索接口参数不匹配的问题。

### 13. 设备目录列表状态与详情不一致
- 现象:数字示波器已有未来已批准预约,列表行仍显示「无预约」。
- 根因:列表行的设备状态仅在首次加载时快照计算,后续预约变更不同步。
- 修复:打开详情弹窗后用实时返回的预约数据就地校正该行状态,保证列表与详情一致。

## 四、物料模块

### 14. 物料模块接口 500(金额字段残留)
- 现象:拉取定稿代码后物料模块相关接口 500。
- 根因:代码仍保留金额相关字段,数据库已按定稿移除对应列。
- 修复:同步移除实体、DTO、VO、Service、前端组件和导入模板中的所有金额字段。

### 15. 物料 SKU 搜索语义不明
- 现象:两个搜索框共用一个混合 keyword 同时匹配码/名称/规格,语义不清。
- 修复:拆分为 `skuCode`、`materialName` 两个独立查询参数,AND 联动;同步调整分页查询、导出逻辑与前端搜索区双 typeahead,移除原分类筛选下拉。

### 16. SkuSelect 组件搜索失效
- 现象:申领表单里 SKU 选择器搜索无结果。
- 根因:pageSkus 参数拆分后 keyword 被忽略。
- 修复:组件内改为 skuCode + materialName 双查并发合并去重。

### 17. SkuSelect 对老师/学生 403
- 现象:老师/学生打开申领表单,SKU 下拉加载 403。
- 根因:pageSkus 需 `item:material:list` 档案权限,老师/学生不持有。
- 修复:新增轻量 `GET /material-skus/options` 接口(挂 `item:request:create`),SkuSelect 增加 `forRequest` 模式区分场景。

### 18. SKU 码输入「1」搜不到任何结果
- 现象:SKU 码搜索要求前缀匹配,输入部分字符检索不到包含该字符的条目。
- 修复:分页查询、导出接口、SKU 选项接口三处的 skuCode 匹配统一由前缀匹配改为模糊全匹配。

### 19. 学生代领菜单不可见(菜单孤儿)
- 现象:「物料代领」菜单对学生代理不可见,功能入口缺失。
- 根因:菜单树只从 parent_id 为空的节点建树,菜单 205 挂在仅绑管理员的目录 151 下成为孤儿。
- 修复:迁移脚本将菜单 205 提为顶层(parent_id=NULL)。

### 20. 代领可冒填他人且缺授权校验
- 现象:PROXY 创建接口信任入参 operatorId/grantId,可冒填他人且无 assistant_grant 校验。
- 修复:代领人强制取当前登录学生、仅学生可代领(40900)、必须持有源单归属老师的有效授权(无授权 40300、命中写 grant_id)。

### 21. 代领剩余量计算 NPE(500)
- 现象:对老师直申单做代领时 500,且可用量显示为 0。
- 根因:老师申领跳过初审直落 TEACHER_APPROVED 时行批准量未写入(null),剩余量计算空指针。
- 修复:老师单行批准量在创建时按申请量同步写入。

### 22. 库存余额对老师/学生不可见
- 现象:老师/学生查看库存余额 403,无法明确看到物料剩余量。
- 修复:`item:balance:list` 补绑老师/学生角色;物料工作台页签改为按接口权限动态过滤,无权限页签直接隐藏避免 403。

### 23. 归还过账 500(结算表列名残留)
- 现象:归还单审批过账时 500,报 `Unknown column 'qty'`。
- 根因:material_settlement 数量列已更名 `quantity`,MaterialSettlementMapper 的汇总 SQL 仍残留旧列名 `qty`。
- 修复:`SUM(qty)` 改为 `SUM(quantity)`。
