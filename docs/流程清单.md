## 二、七大核心业务主流程

### 流程 1：器材借用申请与审批流程

学生/老师选择目标实验室 → 浏览器材列表 → 选择器材与时段 → 提交预约申请，按申请角色分流：

- **老师申请** → 系统判断器材价值分级：
  - NORMAL（普通器材，单价 < 5000 或不在高价值清单）→ 直接 APPROVED；
  - VALUABLE（贵重器材）→ PENDING_ADMIN → 管理员审批（通过/驳回）。
- **学生申请** → PENDING_TEACHER → 推送老师待审批（4 小时未处理催办；超 24 小时未处理推送管理员可代批）：
  - 驳回 → REJECTED，填写驳回原因，通知学生；
  - 通过 → 普通器材直接 APPROVED；贵重器材转 PENDING_ADMIN → 管理员审批。
- 管理员审批：通过 → APPROVED 推送申请人；驳回 → REJECTED 需填原因。

### 流程 2：借出与归还流程（页面确认，强制拍照留痕）

1. 申请人按预约时段到实验室，在借用单上**确认借出** → 强制上传借出外观照 → CHECKED_OUT（器材 IN_USE）；
2. 使用完毕 → 在借用单上**确认归还** → 强制上传归还外观照 → 登记器材状态：
   - GOOD（完好）→ RETURNED，器材恢复 IDLE；
   - DAMAGED（损坏）→ 必填损坏描述 + 损坏部位照 → RETURNED，器材状态立即置 MAINTAINING → 推送管理员与申请人（仅知悉，不生成线上工单）；
3. 管理员线下安排维修 → 系统中登记处理结果：修复 → 恢复 IDLE；无法修复 → 发起报废申请（走流程 7 报废四态流转）。

### 流程 3：超期未还督办流程（定时扫描）

系统每小时扫描使用记录，end_time < 当前时间且状态仍为 CHECKED_OUT：

| 超期时长 | 处置 |
| --- | --- |
| 1 小时 | 提醒申请人 |
| 24 小时 | 升级提醒申请人、管理员 |
| 48 小时 | 冻结该用户未来 7 天预约权限，推送管理员人工介入 |

### 流程 4：物料代办流程（老师助理）

1. 老师添加学生助理 → 设定授权范围（课程/实验室）与有效期 → 助理学生端解锁"物料代办"入口；
2. 课前助理依据老师场地预约单/课程安排 → 到器材室领取物料并确认 → 领用出库登记（经办人=助理，归属=老师课程）；
3. 课后助理收齐物料 → 回库登记（核对数量，差异需备注）→ 流水按 booking_id 关联核销；
4. 授权到期或老师撤销 → 入口自动回收；在途未回库流水保留并由老师/管理员跟进。

### 流程 5：场地预约流程（学生申请须老师背书）

1. 老师发起场地预约，或学生发起申请（用途/课程/班级/人数/时段，可勾选配套器材与物料预登记）：
   - 学生提交 → PENDING_ENDORSE → 推送老师背书：拒绝 → REJECTED 通知学生；背书通过（endorse_teacher_id/endorse_time 留痕）→ 进入管理员审批；
   - 老师提交 → 直接进入管理员审批；
2. 系统校验：实验室启用状态、人数 ≤ 容量、同日开放时段、同室时段不冲突（半开区间）、与课表不冲突；
3. PENDING → 管理员人工审批（学生单展示背书老师与背书意见；不适用超时自动通过；超 24 小时催办；start_time 已过自动失效）；
4. APPROVED → 自动为配套器材生成器材预约；
5. 到 start_time 系统自动置 **IN_USE**（占用状态写入教室使用表，无需人工签到）；
6. 超 end_time+2h 系统自动置 **FINISHED**（无需人工签退；管理员可强制结束）；
7. 物料按实际出库核销、场地使用档案归档。

### 流程 6：配件物料库存流程

1. 管理员采购入库（数量×单价）→ 库存增加；
2. 实验课前老师（或授权助理）领用出库登记：定额内直接扣减；超定额需老师签批；贵重/危险耗材双人签字；
3. 课后工具/仪器配件回库（助理收齐核对）；耗材不回库仅核销；
4. stock_qty < safe_qty → 每日推送管理员直至补充；
5. 学期末盘点（盘盈盘亏生成 ADJUST 流水）→ 月报导出。

### 流程 7：三级保养与报废流程

- **日常保养（DAILY）**：课后由老师/管理员在保养模块手动登记（可关联场地预约单）；
- **周期保养（WEEKLY）**：每周一自动生成计划 → 执行登记；逾期每日催办；
- **深度保养（SEMESTER）**：学期初管理员批量创建计划（含厂商）→ 执行登记；
- **器材报废**：申请（状态锁定 MAINTAINING）→ 技术鉴定 → 审批 → 处置销账（确认数据擦除 → SCRAPPED）。

## 三、支撑性子流程

### S1：助理授权管理流程

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 进入"助理管理" | 展示本人已授权助理列表（姓名、范围、有效期、状态） |
| 2 | 添加助理 | 按学号/姓名搜索本校学生 → 选定 |
| 3 | 设定授权范围 | 勾选本人名下课程和/或实验室（可多选） |
| 4 | 设定有效期 | 选择起止日期（默认本学期末，最长不超过 1 学年） |
| 5 | 确认授权 | 即时生效，无需管理员审核；推送通知并解锁助理"物料代办"入口 |
| 6 | 撤销/调整 | 随时撤销或修改范围、有效期，变更即时生效 |

### S2：损坏异常处理流程

归还登记 DAMAGED 或课中工位故障上报触发：

1. 器材状态立即置 MAINTAINING（损坏描述+照片留痕）→ 推送管理员知悉（**不生成线上工单，维修走线下**）；
2. 管理员线下组织维修，在「损坏异常处理」中回填处理结果（handle_result/handle_user/handle_time）；
3. 修复 → 器材恢复 IDLE；无法修复 → 发起报废申请（转流程 7）；
4. 器材长期 MAINTAINING 未处理 → 每日提醒管理员，纳入看板异常清单。

### S3：工位绑定与故障上报流程

- **绑定/解绑**：老师对本班学生执行绑定/解绑（批量粘贴学号按工位号顺序自动分配）；全局一名学生最多绑定一个工位；
- **课中故障上报**：发现工位异常（缺件/损坏）→ 置 FAULT 并填写现象 → 若工位关联主设备则该器材同步置 MAINTAINING → 推送管理员知悉（维修走线下）；故障工位后续绑定分配自动跳过。

### S4：课程排课导入流程

- 学期初管理员通过 **Excel 批量导入**课程排课表（teacher_id/course_name/weekday/period_start/period_end/week_mask/semester，直接关联 lab_id）；
- 导入数据用于场地预约冲突检测与「教室使用表」周视图（课表+预约合并展示）；
- 教务系统网页抓取对接为二期评估项，一期不做。

## 四、流程异常分支说明

- **拍照失败/模糊**：支持重新拍摄，不允许跳过拍照进入下一环节；
- **网络异常**：表单本地缓存，网络恢复自动重试上传；
- **预约时段冲突**：同一器材同时间段已有 APPROVED/CHECKED_OUT 预约 → 系统阻止提交并提示冲突器材与时段；
- **老师审批超时**：学生借用单 PENDING_TEACHER 超 4 小时（工作时段）→ 催办老师；超 24 小时 → 推送管理员，管理员可代批/代驳回并留痕；
- **高价值器材审批超时**：PENDING_ADMIN 超 4 小时（工作时段）→ 自动推送提醒，超 24 小时 → 自动通过并通知申请人/管理员；
- **场地背书超时**：学生场地申请 PENDING_ENDORSE 超 24 小时 → 催办背书老师；超 48 小时未处理自动 CANCELLED 并通知学生；
- **场地审批不通过/过期**：REJECTED 留档不可编辑，改时段需新建预约单；start_time 已过未审批自动 CANCELLED；
- **归还损坏**：器材长期 MAINTAINING 未处理 → 每日提醒管理员，纳入看板异常清单。

## 五、主要状态机速览

### 5.1 器材预约单

- 学生单：`PENDING_TEACHER` →（老师审批通过，普通器材）→ `APPROVED`；贵重器材 → `PENDING_ADMIN` →（管理员审批通过）→ `APPROVED`
- 老师单：普通器材提交即 `APPROVED`；贵重器材 `PENDING_ADMIN` → `APPROVED`
- `APPROVED` →（确认借出）→ `CHECKED_OUT` →（归还）→ `RETURNED`
- `PENDING_TEACHER` / `PENDING_ADMIN` →（驳回/用户取消）→ `REJECTED` / `CANCELLED`

### 5.2 器材

- `IDLE` ↔（预约生效/借出）`RESERVED` / `IN_USE`
- `IN_USE` →（归还损坏）→ `MAINTAINING` →（管理员回填修复）→ `IDLE`
- `MAINTAINING` / `IDLE` →（报废流程）→ `SCRAPPED`

### 5.3 场地预约单

- 学生单：`PENDING_ENDORSE` →（老师背书通过）→ `PENDING` →（管理员审批通过）→ `APPROVED`
- `PENDING_ENDORSE` →（背书拒绝）→ `REJECTED`；（48h 背书超时）→ `CANCELLED`
- 老师单：提交即 `PENDING`（无背书环节）
- `APPROVED` →（到 start_time 自动）→ `IN_USE` →（到 end_time+2h 自动 / 管理员强制结束）→ `FINISHED`
- `APPROVED` →（开始前用户取消）→ `CANCELLED(MANUAL)`
- `APPROVED` →（管理员仲裁/停用）→ `CANCELLED(FORCE)`
- `PENDING` →（start_time 已过未审批）→ `CANCELLED(AUTO_EXPIRED)`

### 5.4 报废单

- `PENDING` →（提交鉴定）→ `APPRAISING` →（鉴定通过+审批）→ `APPROVED` →（处置销账）→ `DISPOSED`
- `APPRAISING` / 审批环节 →（不通过）→ `REJECTED`（器材恢复原状态）

## 六、角色业务流程步骤（3.3 汇总）

| 步骤 | 操作角色 | 动作 |
| --- | --- | --- |
| 1 | 学生 | 在线提交器材借用申请（含时段、用途），等待老师审批；贵重器材老师批后自动转管理员审批 |
| 2 | 老师 | 审批所带学生的器材借用申请（4h 催办，超 24h 管理员可代批）；本人预约普通器材直接通过、贵重待管理员审批 |
| 3 | 管理员 | 审批 VALUABLE 器材预约（4h 工作时段反馈，超 24h 自动通过）；代批超时学生借用单 |
| 4 | 学生/老师 | 按预约时段在借用单上确认借出，强制上传借出外观照 |
| 5 | 学生/老师 | 使用完毕在借用单上确认归还，强制上传归还外观照，登记 GOOD/DAMAGED |
| 6 | 管理员 | 接收 DAMAGED 推送 → 线下安排维修 → 系统登记处理结果 → 恢复 IDLE 或发起报废 |
| 7 | 老师 | 发起场地预约（勾选配套器材/物料），直接进入管理员审批；对学生场地申请进行背书 |
| 8 | 学生 | 提交场地预约申请 → 经老师背书 → 管理员审批 |
| 9 | 老师 | 按预约时段使用实验室（到点自动 IN_USE，结束自动 FINISHED）；课后手动登记日常保养 |
| 10 | 老师助理 | 课前代领物料并登记出库，课后收齐回库登记；经办人=助理，归属老师课程，授权范围与有效期外不可操作 |
| 11 | 管理员 | 配件采购入库、库存预警处理、学期末盘点与月报导出 |
| 12 | 管理员 | 执行周期/深度保养计划登记，逾期处理；处理报废申请（鉴定→审批→处置销账） |
| 13 | 管理员 | 通过看板监控器材利用率、场地使用率、库存与保养执行情况；督办超期未还与异常器材 |
