## 三、助理授权模块（本次新增）

后端（`com.labmanage.roles`，`/api/v1/system/grants`，均带 `@SaCheckPermission`）：

| 接口 | 权限码 | 说明 |
| --- | --- | --- |
| GET /api/v1/system/grants | system:grant:list | 分页查询本人发出的授权（status 过期按 end_at 派生 EXPIRED） |
| GET /api/v1/system/grants/students?keyword= | system:grant:create | 按姓名/学号联想在校学生（启用中，限 20 条） |
| POST /api/v1/system/grants | system:grant:create | 创建授权，返回 `{ id }` |
| POST /api/v1/system/grants/{id}/revoke | system:grant:revoke | 撤销本人发出的 ACTIVE 授权 |

核心类：`AssistantGrantController`、`AssistantGrantService(Impl)`、`GrantCreateDTO`、`GrantVO`、`StudentOptionVO`；复用既有 `AssistantGrant(Mapper)`、`AssistantGrantScope(Mapper)`。

业务规则（依据 PRD 4.2.6 与数据库设计 4.6）：
- 有效期最长 366 天，`endAt > startAt` 且 `endAt > now`；前端默认今天起 180 天。
- 同教师同学生仅允许一条 ACTIVE 授权，重复创建返回 40900。
- 范围一期仅 `LAB`（scopeType 一期限场地），action 为 `ISSUE`（领用）/`RETURN`（归还）。
- 仅可撤销本人授权（40300）；仅 ACTIVE 可撤销，重复撤销 40900。
- 学生获有效授权后，登录 profile 动态含 `ASSISTANT`（`start_at <= now < end_at` 半开区间）；撤销或到期后重新登录即失效。

前端：`views/grant/GrantManage.vue`（列表 + 新建弹窗 + 撤销二次确认）、`api/grant.js`、`router/dynamic.js` 白名单注册 `/grant`。

## 四、验证结论

### 构建/静态检查
- 后端 `mvn compile` 通过；前端 ESLint、`vite build` 均通过。
- 后端已重启加载新 Controller（dev profile，11.2s 启动完成，8081 监听正常）。

### 助理授权端到端实测（14/14 通过，2026-10-22）
1. teacher01 登录 → 角色 TEACHER；`GET /system/grants` 列表空数据 code=0。
2. 学生联想搜索「测试」→ 命中 student01（id=3，S20260001）。
3. 创建授权（A703 网络实训室，ISSUE+RETURN，30 天）→ code=0，授权 id `2113201550066548737`。
4. 授权后 student01 重新登录 → roles `[STUDENT, ASSISTANT]`（动态角色生效）。
5. 同学生重复创建 → 40900「该学生已有生效中的授权」。
6. 撤销授权 → code=0；重复撤销 → 40900「该授权已撤销或已到期」。
7. 撤销后 student01 重新登录 → roles `[STUDENT]`（动态角色即时移除）。

### 学生只读模式越权探测（看板页）
- 前端：预约/批量/取消按钮由 `v-if="!isReadonly"` + `v-permission` 双控隐藏；点选空闲节次仅改变前端选择态（无副作用，`openBook` 前置 `canBookSelected` 校验）；详情抽屉只读。
- 接口级（student01 token 直调，绕过前端）：创建预约 40300、创建授权 40300、授权列表 40300；看板只读接口 `GET /booking/labs/board` code=0 正常。
- 结论：看板页无未授权数据写入口，前端隐藏仅是体验层，后端 `@SaCheckPermission` 兜底有效。
