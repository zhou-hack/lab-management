### 二、改动摘要

1. **模块全景**：roles（认证/RBAC/用户管理）+ space（单表 lab 场地）+ booking（场地预约）+ equipment（设备分类/型号/台账/迁移/定级）+ item（物料库存全闭环）。
2. **冲突裁决**：
   - 认证统一采用 main 的 roles 模块（账号密码 + 短信验证码、首登建档、二级确认），剔除 `固定设备管理` 分支自带的简化认证；
   - 空间模型以整合 SQL 的单表 `lab` 为准（`数据库设计.md` v1.1 修订），剔除该分支 campus/building/lab 三级空间代码，设备模块适配到 `BizSpace`；
   - `dev/database` 基线快照误回退的公共层（Jackson 3、操作者填充、UTC 序列化严格校验、Bearer 配置）已恢复 main 版本；
   - 前端基座以 `dev/basic_model` 契约为准（store.user/permissions + fetchProfile），`datetime.js` 合并为 Intl 规范实现的全集。
3. **SQL 整合**：`sql/lab_management_all.sql` 补齐预约模块 `lab_booking`/`lab_slot` 建表与 booking 权限/菜单/角色绑定种子（3000 段）；菜单 component_key 统一大驼峰（SpaceLabList/Equipment*/ItemWorkspace）；物料 11 个页面菜单合并为单页「物料工作台」（原页面菜单停用保留）。
4. **前端整合**：动态路由白名单按 component_key 登记全部模块页面；移除 `/item` 临时公开骨架路由；`v-permission` 维持严格语义；`DepartmentOptionVO` 补 parentId 支撑部门树。

### 四、已知限制

- 未做应用级运行验证：本机无 MySQL 8.4，整合 SQL 未真实落库执行；admin 密码散列仍为占位值，部署前必须替换并强制首登修改。
- 场地预约为一期简化审批链（PENDING→APPROVED，无背书/自动 IN_USE/FINISHED）；`equipment_booking`/`equipment_usage` 表结构保留但借用流程未开放。
- Knife4j + springdoc 组合尚未按 AGENTS.md 要求做页面与 Bearer 调试的应用级验证。
- 物料工作台为单页多页签形态，原 11 个页面级菜单停用保留，后续按需拆分。

### 二、改动摘要

本次发布为**场地模块全面优化**，覆盖五个维度：

#### 1. 功能扩展（5 项新能力）

| 功能 | 交付内容 |
| --- | --- |
| 场地预约管理 | `module/booking` 全新模块：发起 / 取消 / 审批 / 驳回 / 我的预约 / 全部预约 / 可用时段 / 详情 / 统计共 9 个接口；`lab_booking` + `lab_slot` 两表；状态机 PENDING → APPROVED / REJECTED，PENDING / APPROVED → CANCELLED |
| 资源分配（时段互斥） | 半开区间重叠判定；待审批不占用时段（提交与审批双重校验）；批准经场地行 `SELECT ... FOR UPDATE` 串行化 + 二次冲突校验，最后批准者遇冲突拒绝不抢占；APPROVED 取消同步释放占用，同时段可再约 |
| 使用统计分析 | 预约按状态计数统计卡（total/pending/approved/rejected/cancelled）；场地统计新增类型分布（typeDistribution） |
| 用户权限控制 | 预约权限码 `booking:lab:create / cancel / list / approve` 前后端一致（SQL 3001-3007 登记）；非本人取消、越权审批、越权查看他人详情均返回 40300 |
| 批量启停 + CSV 导出 | 勾选 ≤100 项批量置 AVAILABLE / CLOSED（返回 updated 计数与 missing 列表，停用二次确认）；按筛选条件导出 CSV（UTF-8 BOM、上海时区展示、上限 10000 行） |

#### 2. 性能优化

- 审批并发采用**行锁**（仅锁目标场地行）代替宽范围锁，冲突窗口最小化
- 名称 / 申请人批量 `selectBatchIds` 内存回填，消除 N+1 查询
- 统计接口单条 `GROUP BY` SQL 聚合，避免逐行计数
- 测试 JVM 与生产对齐 `-Duser.timezone=UTC`（surefire argLine），消除时区换算偏差

#### 3. 代码重构

- 删除前端演示数据层（`space.demo.js` / `space.service.js`），列表页直连真实 API
- `page()` 与 `exportCsv()` 共享 `buildWrapper()` 构造逻辑
- 时间换算统一收敛到 `frontend/src/utils/datetime.js`（显式 +08:00 偏移，禁止裸 `new Date`，含 12 个单测）
- 场地删除补全引用检查（原 TODO）：未结预约（PENDING / APPROVED）+ 未释放 `lab_slot` 占用，命中返回 40900

#### 4. UI / UX 改进

- 新增管理端预约总览页、审批页、前台"我的预约"页、共享预约弹窗（含空闲 / 占用时段可视化辅助）
- 预约表单前端校验 + 后端 Jakarta Validation 双层兜底
- 语义胶囊状态展示（待审批 = 橙、已批准 = 绿、已驳回 = 红）；768px 断点响应式适配

#### 5. 兼容性与版本标识

- 登录页移除测试账号入口，`accountName` 对齐后端契约；ProfileVO 菜单树（DIRECTORY → M / PAGE → C）映射进动态路由白名单
- **全库版本标识统一为 1.1**：pom `0.0.1-SNAPSHOT` → `1.1`、package.json `0.1.0` → `1.1`；文档与 SQL 脚本头 `v2.1 / v2.0 / v0.1 / v1.0` → `v1.1`；预约模块注释 `v1 / v2` 阶段措辞统一为"一期 / 二期"（20 个文件，纯标识替换无逻辑变更）
