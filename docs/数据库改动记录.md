## 2026-10-23 物料核销列表加物料与库位列（无数据库结构变更）

- **改动内容**：物料核销列表新增「物料」「库位」两列——`MaterialSettlementVO` 加 `skuCode/materialName/locationName`（物料经原出库行解析：结算 → `stock_document_line`（skuId）→ `material_sku`），page 批量 enrichment 共 3 次批量查询（行/物料/库位，空集跳过）。库位解析按结算类型分流：**RETURNED（归还单过账自动生成）按归还行 `returnLineId → stock_document_line.toLocationId`（归还入库目标库位）解析**，其余类型按原出库行 `fromLocationId`（出库来源库位）解析；原出库行与归还行同表合并一次批量加载。前端 SettlementPanel 在「原出库行 ID」后加两列（物料显示 `编码 · 名称`，库位显示名称，解析不到回退 '-'）。**数据库无任何结构变更**，无新增迁移脚本。
- **涉及文件**（纯代码）：后端 `MaterialSettlementVO`（+3 字段与 from 新签名）、`MaterialSettlementServiceImpl`（注入 MaterialSkuMapper/StockLocationMapper、enrichIssueInfo 批量解析 + RETURNED 按 toLocationId 分流）；前端 `SettlementPanel.vue`（物料/库位两列）。
