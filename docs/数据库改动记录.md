# 数据库改动记录

## 2026-10-20 库位保管人列落地（旧库迁移；基线未动）

- **改动内容**：`stock_location.custodian_id` 列与外键 `fk_item_location_custodian`（→ sys_user.id，每库位一名）。该列在 2026-10-19 需求定稿时已写入基线 `lab_management_all.sql` 4.3 节，本次仅为建库早于定稿的旧库补列迁移；基线无需变更。
- **涉及文件**：`sql/migrations/item_location_custodian.sql`（新增，幂等：information_schema 判存跳过）、`sql/README.md`（登记与升级顺序）。
- **后端配套**（物料模块，无表结构变更）：库位实体/DTO/VO/服务支持保管人维护（全量编辑语义，传空清除）；新增 `GET /api/v1/stock-locations/custodian-options` 保管人候选搜索（跨模块只读 `sys_user`）；库存流水 VO 增加经手人（入库人/出库人，取单据 `operator_id`）与保管人姓名，列表联查批量解析。
- **旧库迁移**：执行前先整库备份，再跑 `item_location_custodian.sql`（幂等可重复）。
- **验证**：本地 `lab_management` 库备份（`tools/db_backup_before_custodian_20261020_112*.sql`）后执行迁移，`SHOW COLUMNS` 确认列与外键存在；后端单测（库位保管人写入/姓名解析/候选搜索）与前端 lint+test 全部通过。
- **关联文档**：`docs/物料管理模块设计.md` 库位表字段与流水台账说明同步。
