## 2026-10-14 数据库整合

将原本需按依赖顺序手工依次执行的三个建表脚本（`sql/sys_rbac.sql` → `sql/item_material.sql` → `sql/item_phase_2.sql`）整合为一键初始化脚本，消除执行顺序与遗漏风险，并对保留模块做兼容性验证。

### 整合产物（一键脚本 + 正本双轨）

| 产物 | 说明 |
| --- | --- |

## 2026-10-14 CRUD 补全与系统优化

### 变更清单

| 层 | 变更 |
| --- | --- |
| SQL 正本 | 还原 `sql/item_phase_2.sql`（自 init_lab_management.sql 抽取，生成器重组零差异校验通过）；`sql/item_material.sql` 追加删除权限 138-140、删除菜单 200-202、角色绑定（sys_role_permission 238-240、sys_role_menu 350-352）及 3 个查询索引（idx_item_stock_doc_occurred、idx_item_request_status、idx_item_stocktake_status）；生成器 `tools/gen_init_sql.ps1` 增加新增索引断言；增量迁移已在本地库执行（ALTER/INSERT，未整库重建） |
| 后端接口 | 新增 3 组 DELETE 端点（/material-categories/{id}、/material-skus/{id}、/stock-locations/{id}），带引用检查：被引用时返回 40900（分类被 SKU 引用、SKU 被余额/申领/定额/核销引用、库位被余额/盘点引用不可删） |

| 后端性能 | 单据行/流水写路径由逐条 insert 改为 insertBatch 批量化 |
| 前端功能 | 新增基础数据页签（BasicDataPanel：分类/SKU/库位三段 CRUD 弹窗）、余额页签预警配置弹窗与"仅看预警"开关（切 pageWarnings 数据源）、各面板过滤维度对齐后端 Query DTO（流水面板加库位/方向/单据/时间范围过滤等） |

| 前端安全 | 全面板按钮铺设 v-permission（权限码与后端 @SaCheckPermission 逐一对齐）；hasPermission 对空权限集放行以兼容未登录骨架页（接口鉴权仍以后端 Sa-Token 为准），配套 Vitest 用例固化 |
